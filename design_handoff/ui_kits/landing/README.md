# UI Kit — Landing Page

Site de marketing single-page para **Vagas Guarujá**. Apresenta a plataforma para dois públicos: candidatos e empresas. Estrutura:

1. **Header** com nav + CTA
2. **Hero** — proposta + 2 CTAs (candidato / empresa)
3. **Stats** — números sociais
4. **Para candidatos** — 3 features com mockup do app
5. **Para empresas** — 3 features com mockup do painel
6. **Como funciona** — 4 passos
7. **Pricing** — 3 pacotes de créditos
8. **FAQ** — perguntas comuns (LGPD, créditos, prazo)
9. **Footer** — links, redes, legal

Tudo em um arquivo `index.html`.
